## 2. File Change Registry & Explanations

Here is a summary of the modified files, their repository paths, and the exact reasons they were updated:

### 📄 1. GitHub Actions Deployment Pipeline
*   **Path in Project:** [.github/workflows/cicd.yml](../../.github/workflows/cicd.yml)
*   **Packet Path:** [github_actions/cicd.yml.template](./github_actions/cicd.yml.template)
*   **Why it Changed:**
    *   Added runtime environment variable injection for `MONGODB_URI` using `export MONGODB_URI='${{ secrets.MONGODB_URI }}'` in the deployment shell before starting docker compose.
    *   Fixed container recreation and cache issues to prevent old configurations from being reused.
    *   Ensured security hygiene by executing `docker logout` after image pulls on the target VM to eliminate active credential caching.

---

### 📄 2. Docker Compose Production Template
*   **Path in Project:** [docker-compose.production.template.yml](../../docker-compose.production.template.yml)
*   **Packet Path:** [docker/docker-compose.production.template.yml](./docker/docker-compose.production.template.yml)
*   **Why it Changed:**
    *   Removed the local MongoDB database service and its persistent volume definition.
    *   Configured the `backend` service to fetch its database uri dynamically from host environment using `MONGODB_URI: ${MONGODB_URI}`.
    *   Added healthcheck controls and structured log limits for the backend API container.

---

### 📄 3. Production Environment Skeleton
*   **Path in Project:** [.env.production](../../.env.production)
*   **Packet Path:** [environment/env.production.template](./environment/env.production.template)
*   **Why it Changed:**
    *   Removed the database connection string completely to satisfy the Zero-Filesystem-Secrets requirement.
    *   Defined backend routing endpoints (`VITE_API_URL`, `CORS_ORIGIN`) for the host VM.

---

### 📄 4. Git Ignore Rules
*   **Path in Project:** [.gitignore](../../.gitignore)
*   **Packet Path:** [environment/gitignore.template](./environment/gitignore.template)
*   **Why it Changed:**
    *   Ensures that `.env` and local credentials generated by the developer or pipeline run are strictly untracked by Git, preventing leakage into upstream source control.
