## 1. Runtime Integration Map

The integration connects the canonical task/observation runtime (Group 1/3) with the Group 2 Scientific Context via standard API contracts, feeding into SANSKAR for contextual intelligence.

**Architecture Flow:**
`[Shared Runtime / Canonical DB]` → `HTTP POST /context/resolve` → `[Group 2 Context Service]` → `HTTP POST /sanskar/signal` → `[SANSKAR]`

*   **Group 2 Context Service:** Intermediate service responsible for mapping Canonical Observation IDs to structured Scientific Context Records.
*   **SANSKAR Capability:** Analyzes context + observation, returning semantic intelligence scores.
