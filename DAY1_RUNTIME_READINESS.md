## 3. Restart & Recovery Evidence

The ecosystem utilizes Docker Compose bounded boundaries using `restart: unless-stopped`. 

* **Failure Emulation**: Dropping the database container immediately orphans backend dependencies.
* **Recovery Mechanism**: Docker swarm/engine handles continuous respawn operations automatically if processes terminate due to OOM or bad connections.
* **Healthcheck Retries**: `docker-compose.yml` natively implements `healthcheck` testing logic (`curl -f http://localhost:5000/api/ping` with `15s` check intervals, retrying 3 times) to guarantee container orchestration acts correctly and marks the service as `unhealthy` if unrecoverable.
